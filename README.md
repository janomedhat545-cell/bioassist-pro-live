# BioAssist Pro 🧬🤖

**BioAssist Pro** is an AI-powered biotechnology learning and research workspace engineered for molecular biology, cancer research, genetic engineering, and routine laboratory calculations.

---

## 🌟 Key Features

### 🧪 1. Quick Lab Calculator
- **Molarity Calculator:** Supports multiple operational modes, automated unit normalization, and common reagent presets.
- **Dilution Calculator ($C_1V_1 = C_2V_2$):** Multi-unit normalization across concentration and volume with validation warnings.
- **PCR Reaction Setup:** Configurable tube count, master mix overage slider, and automatic water balancing.

### 🧬 2. CRISPR & Genetic Engineering Reference Guide
- Curated library covering CRISPR fundamentals, DNA repair pathways (NHEJ vs HDR), base editing, and cancer genomics.
- Real-time search, multi-category filtering, and interactive learning mechanisms.

### 🤖 3. BioAssist AI Assistant
- Integrated via Gemini AI model for specialized Red Biotechnology queries, lab protocol guidance, and experimental controls.

---

## 🛠️ Tech Stack
- **Frontend:** React, TypeScript, Tailwind CSS
- **AI Integration:** Google GenAI / Gemini API
- **Tooling & Environment:** Google AI Studio, Vite
